## ✨ Features

| Feature | Details |
|---|---|
| **Current weather** | Temperature · Real feel · Sunrise & sunset times · Weather icon |
| **Hourly forecast** | Today's 3-hour interval slots — time, icon, forecast, temp, feel, wind |
| **5-day forecast** | One card per day — icon, temperature, weather type; click any card to expand hourly |
| **Nearby places** | Auto-fetches weather for 4 surrounding coordinates (±1° lat/lon) |
| **404 handling** | Unknown city name shows a friendly 404 illustration |
| **Weather icons** | Custom PNG icons for Sun ☀️, Clouds ☁️, Rain 🌧️, Moon 🌙 |

## 🔬 How It Works

```
User types city name → clicks 🔍
              │
              ▼
     Weather.setPageWeather(city)
              │
    ┌─────────┴─────────────────┐
    │ Today tab selected        │ 5-day tab selected
    ▼                           ▼
urlToday(city)              url5d(city)
    │                           │
    ├── GET /weather?q=city      └── GET /forecast?q=city
    │   → setCurrentWeather()           → set5dWeather()
    │     [CURRENT WEATHER card]          [day cards grid]
    │                                       │
    ├── GET /forecast?q=city            User clicks a day card
    │   → setHourlyWeather()                │
    │     [HOURLY table — today only]       └── setHourlyFromDay(day)
    │                                           [HOURLY table for that day]
    └── GET /weather?q=city
        → setNearbyWeather()
          reads lat/lon, fires 4 requests:
          ┌── (lat-1, lon-1) → nb1()
          ├── (lat-1, lon+1) → nb2()
          ├── (lat+1, lon-1) → nb3()
          └── (lat+1, lon+1) → nb4()
              [NEARBY PLACES card]
```

All API calls use `XMLHttpRequest`. Responses are parsed and injected
as template literals into `.infoItems` via `insertAdjacentHTML`.

## 🚀 Getting Started

### Option A — Open directly (no build needed)

The `dist/` folder is already built. Just open it:

```
dist/index.html   ← open this in any browser
```

No server required — all assets are local, API calls go directly to OpenWeatherMap.

---

### Option B — Build from source

**Prerequisites:** [Node.js 16+](https://nodejs.org/) and npm.

```bash
# Install dependencies
npm install

# Build to dist/
npm run build
```

Then open `dist/index.html` in your browser.

## 🏗 Build

Webpack is configured in `webpack.prod.js`:

| Setting | Value |
|---|---|
| Entry | `./src/script.js` + `./src/style.css` |
| Output | `./dist/index_bundle.js` |
| HTML | Generated from `./src/index.html` via `HtmlWebpackPlugin` |
| JS transpilation | Babel 7 (`@babel/preset-env`) |
| CSS | `style-loader` + `css-loader` (inlined into bundle) |
| Mode | `production` if `NODE_ENV=production`, else `development` |

```bash
npm run build
# → dist/index.html
# → dist/index_bundle.js
```

## 🛠 Tech Stack

| Technology | Purpose |
|---|---|
| Vanilla JS (ES6 class) | Single `Weather` class — all state and rendering |
| XMLHttpRequest | API calls (no fetch, no axios) |
| Webpack 5 | Bundling JS + CSS into a single output file |

| HtmlWebpackPlugin | Generates `dist/index.html` from the template |
| Font Awesome 5 | Search icon (`fa-search`) via CDN |
| OpenWeatherMap API | Weather data — current and 5-day forecast |

## 🌐 API Reference

Two OpenWeatherMap endpoints are used:

### Current weather
```
GET https://api.openweathermap.org/data/2.5/weather
    ?q={city}&appid={key}&units=metric
```
Returns: temperature, feels_like, weather condition, coordinates, sunrise/sunset.

### 5-day / 3-hour forecast
```
GET https://api.openweathermap.org/data/2.5/forecast
    ?q={city}&appid={key}&units=metric
```
Returns: a list of 40 entries (5 days × 8 per day), each with temperature, feels_like, wind, weather condition.

### Nearby (lat/lon variant)
```
GET https://api.openweathermap.org/data/2.5/weather
    ?lat={lat}&lon={lon}&appid={key}&units=metric
```
Called four times with `(±1°, ±1°)` offsets from the searched city's coordinates.

> **Note:** The API key is embedded in `src/script.js`. To use your own key,
> replace the `wApi` value in the `Weather` class constructor with a key
> from [openweathermap.org](https://openweathermap.org/api).
